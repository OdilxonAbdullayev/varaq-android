# VARAQ uchun kelgusi rivojlanish rejasi

## 1.0 — offline MVP (ushbu ZIP)

Bosh sahifa, shaxsiy kutubxona, kitob CRUD, o‘qish sessiyasi, iqtiboslar, statistika, o‘zbekcha UI, dark mode, kunlik eslatma, JSON backup, Founder Reader.

## 1.1 — sinovlardan keyin

- Test natijalariga ko‘ra xatolarni tuzatish
- Accessibility: yirik matn, TalkBack, kontrast, kichik ekran, landshaft
- 1000+ kitobli ishlash tezligi va muqova xotirasini optimallashtirish
- Kitobni qayta o‘qish (har bir o‘qish tarixi alohida)
- Sessiyani ilova yopilganda ham tiklash, bildirishnoma orqali davom ettirish
- Export/import versiyali migratsiyalar, xato faylga qarshi qo‘shimcha validatsiya
- Unit/UI testlar, Crash monitoring foydalanuvchining roziligi bilan

## 2.0 — foydalanuvchilar ko‘payganda

- Google login va Firebase/alternativ bulutli sinxronlash
- Qog‘oz kitob ISBN orqali qo‘shish; katalog huquqlari / API limitlarini tekshirish
- Kamera orqali matnni tanib olish (OCR)
- Bir nechta qurilmada ishlash va conflict resolution
- O‘zbekcha kirill, ruscha, inglizcha tarjimalar

## 3.0 — ommaviy hamjamiyat

- Do‘stliklar, kitob klublari, birga o‘qish marafonlari
- Ochiq/yopiq profillar va shaxsiy qaydlar uchun nazorat
- Moderatsiya, shikoyatlar, bloklash, kontent siyosati
- GDPR/mahalliy shaxsiy ma'lumot talablari, privacy policy, data export/delete
- Backend xarajatlarini nazorat qilish, masshtablash

**Eslatma:** ushbu ZIP tayyor Google Play nashri emas. Play uchun yig‘ma build, haqiqiy qurilma sinovi, ishlab chiquvchi akkaunti va tegishli siyosatlarni bajarish kerak.
