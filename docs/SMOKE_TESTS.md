# VARAQ — qurilmada qo‘lda test qilish ro‘yxati

Har bir testni haqiqiy Android telefonda (kamida Android 8) tekshiring. Ushbu testlar yozilgan, lekin bu muhitte Android SDK yo‘qligi sababli bajarilmagan.

- [ ] 1. Ilova o‘rnatilganda ism va ikki maqsad so‘raladi.
- [ ] 2. Bo‘sh ism va noto‘g‘ri sonni kiritib ro‘yxatdan o‘tish bloklanadi.
- [ ] 3. Kitob nomi va 320 sahifa kiritib qo‘shiladi; kutubxonada ko‘rinadi.
- [ ] 4. Kitobga JPG/PNG muqova tanlanadi; telefonni qayta ochganda ham to‘liq ko‘rinadi.
- [ ] 5. Kitob nomi bo‘yicha qidirish va uch holat filtrlari ishlaydi.
- [ ] 6. Kitob tafsilotidan tahrirlanadi va yangilangan ma'lumot saqlanadi.
- [ ] 7. Yangi kitobda taymer boshlanadi, pauza qilinadi, 20-sahifa kiritiladi.
- [ ] 8. Sessiyadan chiqishda sahifa progressi va bugungi statistika o‘zgaradi.
- [ ] 9. 320 sahifadan ortiq qiymat kiritib bo‘lmaydi, xato yozuvi chiqadi.
- [ ] 10. Iqtibos + sahifa va shaxsiy fikr qo‘shiladi, kitob bo‘yicha filtr ishlaydi.
- [ ] 11. Qayd o‘chiriladi va keyingi ochilishda tiklanmaydi.
- [ ] 12. 7 kunlik grafik va yillik maqsad real ma'lumotlardan hisoblanadi.
- [ ] 13. Sozlamada ism/maqsadlar va light/dark rejim o‘zgaradi.
- [ ] 14. Eslatmalar yoqilganda Android 13+ da notification ruxsati so‘raladi.
- [ ] 15. Eksport qiling, yana kitob qo‘shing, import qiling: importdan keyin oldingi zaxiradagi ma'lumot tiklanishi kerak.
- [ ] 16. `VARAQ-BIRINCHI` kodini yozganda Founder Reader tabrigi ochiladi.

**Muhim chekka holatlar:** 0 sahifali kitob bloklanishi; internet o‘chirilganda ishlashi; ilovani yopib qayta ochganda ma'lumotlar qolishi; import qilinayotgan JSON buzilgan bo‘lsa ma'lumotlar o‘zgarmasligi; o‘chirilgan kitob bilan bog‘liq qaydlar va sessiyalarning o‘chishi.
